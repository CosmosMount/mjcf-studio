# MJCF Studio

本地运行的 MJCF 可视化编辑器。React / Three.js 负责交互，Python / MuJoCo 负责模型、惯性和仿真。默认中文；无需云账户。

## 启动

在仓库根目录执行（已在 Linux、Python 3.10、Node.js 22 验证）：

```bash
UV_CACHE_DIR=/tmp/mjcf-uv-cache uv sync --frozen
npm ci --cache /tmp/mjcf-npm-cache
./start.sh
```

打开 **http://127.0.0.1:8765**。服务仅监听本机。可用 `MJCF_PORT=8766 ./start.sh` 更换端口。启动脚本构建前端后启动服务；开发时可分别运行 `uv run uvicorn backend.app:app --port 8765` 和 `npm run dev --workspace=mjcf-workbench-ui`。

Python 与 npm 依赖分别锁定在 `uv.lock` 和根目录 `package-lock.json`。MuJoCo 渲染默认使用 EGL；需本机 OpenGL/EGL 驱动，也可通过 `MUJOCO_GL` 选择 MuJoCo 支持的后端。

## 使用

1. **导入**：选择 MJCF/OBJ 及所有关联文件，或选择完整目录；多文件 XML 指定主入口。OBJ 明确选择米、毫米或厘米。支持独立打开或添加到当前模型；追加时自动加名称前缀。多材质 OBJ 的表面保留在同一刚体内。
2. **编辑**：模型树选择对象，拖动平移/旋转操作器或输入参数。显示设置支持毫米、角度；内部始终采用 SI 单位。需要在指定姿态下观察时，用关节滑块或旁边的数值输入；无界关节的滑块窗口仅为 ±π rad / ±1 m，数值输入不受该窗口限制。
   **鼠标驱动机构**：点击工具栏链条图标“拖动关节（保持闭链）”，拖动关节圆点或选中 hinge 的圆环。圆点支持左右/上下拖动转角，圆环支持绕轴拖动；slide 沿投影轴移动。同模式下滑块和数值输入也会求闭链。其他标量关节自动联动，固定 free/ball 的当前状态，检查活动等式、关节限位与肌腱行程；求解失败时不提交候选。首次从不满足限位/行程的姿态开始时，其他关节可能同步调整。原“平移/旋转”仍用于编辑对象参数。
3. **拆分**：选择 mesh 几何体，切换点击、框选或刷选；支持减选、反选、连通扩选及穿透。正视配合穿透框选便于按现有三角面边界拆分。预览中橙色线为开口边界，关闭预览不会修改模型。
4. **补洞和关节**：简单平面边界可预览补洞，非平面或无效结果明确拒绝。拆分时可创建子刚体与 hinge，并明确选择随动的子结构、site 和其他几何体。补面可单独设置外观；新增关节会重排关键帧坐标。
5. **物理与外观**：物理面板选择实际实体，使用各零件材料密度、统一密度、实测质量或手动完整惯性。多个材质面的开口表面可在同一刚体、同一密度下组合成封闭实体计算。外观面板支持颜色、透明度、高光、棋盘纹理及本地图片，保留 UV；不会自动改变摩擦。
6. **检查与导出**：关联面板编辑闭环、肌腱路径和传动参数；仿真显示接触与闭环残差。MuJoCo 渲染用于核对实际外观。下载工程副本可保留未完成草稿；导出需通过编译、惯性确认、100 步数值检查和重载检查，得到独立 XML 与资源 ZIP。

**两个示例**可从侧栏直接打开，也在 `examples/` 提供：`complex.xml` 包含闭环、肌腱、执行器、传感器和关键帧；`split.obj` 是可进行两侧补洞的细分长方体。

## 坐标与惯性约定

- 四元数顺序为 **[w, x, y, z]**；质量 kg，质心位置 m，质心处完整惯性张量 kg·m²。专用计算对话框使用 SI 单位；单位切换用于属性检查器和关节读数。
- “重定义坐标系”补偿几何、子结构、惯性和关节数据，保持机构。ball/free 的关键帧四元数和速度同步换算。自由关节原点移动若不能用现有常量传动等价表达，会定位到执行器并拒绝修改。
- “重新标定读数零点”采用 `q_new = q_old - offset`。固定肌腱和带偏置的执行器不能一律自动换算，必须在同一事务中提供相应参数；编辑器不会声称未知外部控制代码已同步修改。“机械参考姿态”则明确改变连杆构型。
- OBJ 初始显示所用的 MuJoCo 推断惯性不作为已确认物理属性。新几何标记为待确认，禁止直接仿真/导出；自动计算使用原始闭合表面，绝不拿凸包质量代替用户的实体。平面片仅以零质量视觉表面编译，不进行薄壳质量估计。
- 默认不自动改变导入的显式惯性。几何变化后需重新确认。普通 MuJoCo mesh 碰撞采用其原生碰撞行为；视觉凹网格不等于精确凹碰撞体。
- 原 XML 允许标准化、合并和重排，数值往返采用 MuJoCo 原生序列化精度；导出不覆盖原始文件；显式“保存”写回已关联的原文件。工程包用初始模型、资源及编辑命令保存草稿，版本为 1。
- 闭链拖动是运动学预览，不施加鼠标力、不求碰撞，也不修改关键帧或模型参数。成功后速度清零；原生约束坐标最大残差须不超过 `1e-6`（并非所有分量都是米）。局部求解不能保证任意机构/奇异姿态都可达；含柔性体或全局关闭等式约束的模型明确拒绝。

## 验证

```bash
uv run pytest
npm run build
npx playwright install chromium
# 另一个终端先运行 ./start.sh
npm run test:e2e
# 使用独立测试服务时：MJCF_TEST_URL=http://127.0.0.1:8766 npm run test:e2e
```

测试位于 `.agents/tests/`：解析惯性、尺度与旋转、复杂模型往返、关节零点、多个姿态下的坐标重定义、四元数关节关键帧和动能、子结构引用保留、网格/UV/补洞、资源退役与撤销、HTTP/WS、真实画布拖动/框选/补洞/仿真/渲染/工程重开与导出。测试使用独立示例，会替换正在运行的测试服务中的内存模型，请先保存自己的工程。

## 接口与边界

- `GET /api/scene`：模型快照、对象 ID、修订号和诊断。
- `POST /api/command`：`{revision, op, target, args}`；支持编辑、批量事务、撤销重做。对象 ID 为 `类型:名称`。
- `POST /api/import`：multipart 资源、入口、尺度、打开/追加模式。
- `POST /api/geometry/preview`：选面拆分/补洞预览，不提交模型。
- `POST /api/simulation`：姿态、控制量、关键帧、运行/暂停/复位。
- `GET /api/archive?draft=true|false`：工程草稿或验证后的模型。
- `GET /api/render`、`GET /api/texture/{name}`：原生渲染与纹理。
- `WS /api/live`：姿态、接触、约束残差和工作状态。

单用户、单活动模型，内存撤销保留最近 40 次操作；资源上传和工程解包总量限制 512 MiB、ZIP 最多 10000 个条目。不包含自由曲线重网格化、布尔运算、自动机构设计、薄壳质量估计、在线素材或 PBR 编辑。Three.js 为交互预览，最终外观以 MuJoCo 渲染为准。真实大型 CAD 的性能未建立基准。

需求与设计的唯一来源分别为 `.agents/docs/SPEC.md` 和 `.agents/docs/DESIGN.md`；实施和验证状态见 `.agents/plans/plan_editor_1.md`。

### 两关节测量与水平配合
右侧“测量与水平配合”选择关节 A/B，或从模型树选中关节后点“使用选中”。视口显示中心连线，面板显示距离（mm）、坐标差及仰角（度），可选择世界或刚体坐标系。默认允许所有 hinge/slide 参与配合；可展开“允许配合调整的关节”取消不希望调整的关节，再执行“连线水平配合”。闭链机构通常需要包含相关被动关节，否则可能不可达；失败保留原姿态。

水平指所选坐标系中的高度差为零。成功后可“保存水平参考姿态”为命名关键帧，或选中需要标定的关节并进入已有零点事务。参考姿态可以在关联面板加载，并随工程/导出保存。配合只调整当前预览，不添加永久等式约束，也不保证无碰撞或路径可达。

### 保存回原文件
“打开本地文件”填写 XML 或 .mjcfproj 的绝对路径，打开后点击“保存”直接写回该路径。浏览器上传拿不到原始完整路径，首次保存需指定。保存 XML 会保留标定 ref 和关键帧并写入所需资源，原 include 可合并；不会自动保存当前仿真姿态为关键帧。原文件已被其他程序修改或页面模型过期时拒绝覆盖。“下载工程副本”和“导出 MJCF”仍单独提供。

资源命名：保存 XML 和导出 MJCF 使用 `关节名_刚体名`，无关节时用 `fixed_刚体名`；共用网格取首个拥有者，多网格或同名不同内容追加数字编号。纹理采用纹理名。只修改颜色会更新 XML，已存在且内容相同的资源不重写。不会自动删除目录中旧资源，以免影响其他模型。
