## 关键修正与累计复审

- MjSpec 原生名称缓存不包含同事务刚创建对象：名称分配/查找直接检查当前 spec 集合。
- 原生 attach 不复制 Python VFS 字典：追加时显式合并资源，冲突失败；关联及关键帧经测试保留。
- 原生元素删除/重挂接可能级联改变引用：拆分时通过规范 XML 节点移动保留实际关联，并按关节名称重新映射关键帧。
- 面角 UV 无法通过简单内联网格无损保存：生成 OBJ 资源保留独立索引；编译居中变换与作者坐标分开用于显示/编辑。
- 封闭实体质量使用源表面而非推断凸包；生成视觉片标记惯性待确认，仿真/导出有明确门槛。
- 快速框选的相机矩阵尚未更新：拾取前同步世界矩阵。WebSocket 姿态/修订号成对获取，避免旧姿态与新修订混用。
- 最后一轮浏览器回归暴露滑块步长与 ±π 边界不对齐，以及异步示例响应清除新选择的问题；已在负责该行为的输入/状态更新处修复并重跑全部浏览器测试。
- 读数设零保留当前预览姿态、速度及 mocap 状态，独立回归比较变换前后世界几何。
