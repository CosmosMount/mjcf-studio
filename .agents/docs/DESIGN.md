# MJCF Studio 架构

需求以 [SPEC.md](SPEC.md) 为准。实现采用本地 FastAPI + MuJoCo 3.15、NumPy/SciPy/Trimesh，以及 React/TypeScript/Three.js；精确依赖由 uv.lock 和根 package-lock.json 锁定。入口为 start.sh，默认仅监听 127.0.0.1:8765。单用户、单活动工程，不包含云服务。

## 模型与资源

`backend/model.py` 的 Editor 持有 MjSpec，作为 MJCF 语义事实来源；编译得到 MjModel/MjData。源三角网格、面角 UV/法线、材料来源、惯性待确认标记和编辑命令属于工程数据。前端持有场景快照及服务端仿真姿态，不建立独立运动学模型。全程 SI 单位、wxyz 四元数；单位切换在界面边界完成。

导入解析 include 和资源相对路径，禁止逃出导入根目录；OBJ/MTL 在 Trimesh 读取前检查关联图片，避免库静默丢弃缺失纹理。OBJ 多材质面保留在同一刚体。追加 MjSpec 时显式合并 Python VFS 资源，处理名称前缀与冲突。编译错误保留为诊断，不能删除未知模型元素来“修复”模型。

对象 ID 为类型与名称。场景渲染使用编译网格及对应 geom 世界变换，编辑操作器使用作者坐标，避免重复应用 MuJoCo 的网格居中变换。生成网格写成 OBJ 资源，保留独立面角索引，避免内联 XML 对 UV 往返的限制。仅清理确定不再引用的编辑器生成资源；输入资源保留。

## 事务与持久化

命令包含 revision/op/target/args，修订冲突明确拒绝。事务复制 spec 和元数据，错误回滚；撤销/重做保留最近 40 次模型快照。允许编译不成功的草稿，但不能作为有效模型导出。所有模型操作由同一锁保护；重操作在线程池执行，仿真和 WebSocket 使用非阻塞取锁，进度与姿态独立传输。姿态与 revision 成对获取，前端拒绝过期模型响应。

工程包版本 1 保存初始规范 MJCF、资源及命令日志；打开时重放，因此未完成草稿也能保存。有效导出输出独立 XML 和资源，检查惯性待确认状态、原生编译、100 步有限数/原生数值告警及重新载入。上传/解包总量上限 512 MiB，ZIP 最多 10000 项。导出不覆盖源文件；显式本地保存遵循下述来源关联。

## 几何、物理与坐标

`backend/geometry.py` 实现源面拆分、焊接拓扑诊断、边界环和平面补洞、封闭体积分、主惯量校验与平行轴合并。只接受可靠的平面补洞；遇到非流形、自交等问题明确拒绝自动实体计算。视觉片可以编译预览，但不使用推断凸包或薄壳质量作为已确认惯性。物理质量集合由用户明确选择；导出使用显式惯性，避免视觉/碰撞重复计量。补面可成为独立外观几何，质量仍由完整表面计算。

拆分、子结构迁移使用规范 XML 节点移动后重新解析，避免原生删除/重挂接级联丢失引用。新增关节按旧/新编译地址映射关键帧。坐标重定义补偿几何、关节、site、子结构、相机、惯性与有关约束，ball/free 同步换算关键帧四元数和速度；无法用原有传动表达的变化明确拒绝。读数设零处理 ref、springref、限位及关键帧，保持当前预览姿态；固定肌腱及不能自动等价处理的执行器需在同事务提供关联更新。机械参考姿态是独立操作。

## 界面与接口

`frontend/src/Viewport.tsx` 管理 Three.js 资源、拾取、轴操作器、面选择及可视化；每次拾取前同步相机/对象矩阵。点击、刷选、框选支持可见/穿透、增减与连通扩选。拆分/补洞预览不写模型，提交带预览修订号。`forms.tsx` 集中各编辑表单，`main.tsx` 负责请求和应用状态。MuJoCo EGL 渲染提供最终外观对照，Three.js 材质仅为交互预览。

HTTP/WS 接口和运行命令见根 README；pytest 验证真实后端计算与语义，Playwright 操作生产构建中的实际画布及控件。验证事实只记录在唯一活动计划中。

## 闭链鼠标拖动

`backend/kinematics.py` 在独立 MjData 中求解指定关节读数，free/ball 保持原值，其他标量关节带界优化。使用原生 kinematics/comPos/tendon/makeConstraint 更新活动等式残差，并检查肌腱限位；无碰撞计算，候选不写入真实状态。明确通过原生约束坐标 1e-6 门槛才提交 qpos 并清速度；失败保留上个状态。API 要求模型修订号，前端将鼠标事件合并到单一串行请求，状态更新继续走原姿态管道。Three.js 圆点/圆环用于拾取与轴向输入，和原参数变换操作器分开。测试可通过 MJCF_TEST_URL 指向独立服务。

## 测量与配合
Measurement 面板读取原生状态的关节世界中心，Three.js 只做测量坐标表达与连线显示。align_joints 复用闭链优化器，添加所选坐标系 Z 方向的中心差残差；用户明确选择优化自由度，free/ball 固定，退化连线拒绝。save_pose 命令保存显式 qpos 为命名关键帧，事务日志可重放；不会把预览操作隐式改成模型零点。参考姿态保存与指定关节零点校准分别执行。

## 本地来源与保存
Editor 持有 source_path/source_digest，仅由本地打开或显式保存设置，不信任上传工程携带的路径。open-local 按路径加载 XML/工程；save 校验修订号、目标和外部文件摘要。persistence.py 复用有效导出校验，将资源按关节与刚体命名并重编译后原子替换主文件；同名不同内容追加编号，已有相同内容不重写。原 include 可合并为单一规范 XML；不删除旧资源或 include 文件。另存工程保持草稿语义。
