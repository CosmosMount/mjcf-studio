# MJCF Studio 需求与验收
本地单用户浏览器 + Python 编辑器；内部米/千克/秒/弧度，中文界面。完整流程：复杂 MJCF/OBJ 导入、自由选面拆分与补洞、材料与惯性、关节/坐标/零点、复杂关联编辑、仿真和独立 MJCF 导出。显式“保存”可写回已关联原文件；导出与下载副本不覆盖来源。

## 必需行为
- 保持 include/default、关节顺序、闭环、多关节刚体、空间/固定肌腱、执行器、传感器和关键帧语义。不得静默丢弃模型元素。
- Three.js 与 MuJoCo 编译变换一致；选择/隐藏/隔离/透明、轴/site/质心/惯性/碰撞显示。
- MjSpec 是模型事实来源；修订号事务、撤销重做、草稿保存打开。仿真状态不是第二套模型。
- hinge/slide 创建编辑，世界/局部输入；移动部件与保持世界几何的坐标重定义分离。读数标定与机械参考姿态分离；转换关联数据，不能等价转换时精确报错并要求同事务解决。
- 自由选面：点击/刷选/框选/加减/反选/连通扩选/穿透。保留面角 UV/法线/材质；沿现有三角面拆分，补洞预览。检查退化/非流形/法向/自交/封闭。实体归属显式选择，碰撞与视觉分开，拆分后惯性过期。
- 密度/实测质量均匀估计/手动完整惯性。只对有效封闭体自动计算，多零件平行轴合并。导入显式惯性不自动覆盖。材料密度有来源，可编辑；外观不决定摩擦。颜色/透明/反光、程序纹理、本地图片/UV 平铺；MuJoCo 渲染核对。
- 约束/肌腱/执行器关系显示及参数编辑；仿真与运动学预览分开，闭环残差/接触/关键帧/控制量。
- 导出前编译、资源检查、短仿真，重载验证；独立 XML+assets。草稿可保存但不冒充有效导出。

## 验收与边界
pytest：模型往返、多姿态坐标重定义、零点耦合、网格面/UV守恒与异常、解析惯性与尺度规律。Playwright：真实选择/拖动/拆分/补洞/设零/保存重开/导出。两个示例：OBJ 和闭环肌腱。全部阶段完成才整体交付；分别记录 PASS/FAIL/NOT_RUN/BLOCKED。无云/多人/在线素材/薄壳估计/曲线切割/自动机构设计/PBR 承诺。

## 鼠标关节驱动（2026-10-08 用户新增）

独立“拖动关节（保持闭链）”模式，在视口直接驱动 hinge/slide。用原生等式残差、关节限位和肌腱行程求可行姿态；不可达/不收敛时不提交候选，不以拉开机构或动力学软约束代替。保留原对象参数编辑与非约束滑块预览。操作仅改变预览状态；不自动保存为关键帧。碰撞、动力学及自由根驱动不属于本次新增承诺。

## 两关节测量与水平配合
关节中心实时测距、坐标差和仰角，支持世界/指定刚体坐标系。水平配合默认允许所有 hinge/slide，可手动取消勾选；仅调整最终勾选的标量关节，并保持原等式、关节限位和肌腱行程；失败不提交。参考姿态保存为关键帧，可撤销与工程重放；指定关节设零复用已有标定规则。配合不保证无碰撞或运动路径可达，不自动添加永久 MJCF 约束。

## 本地原文件保存
用户要求“保存”写回原文件。通过本地完整路径打开会记录来源；浏览器上传无绝对路径时首次保存由用户指定。XML 保存验证编译和资源，原子替换主文件；新增网格资源按关节名与 link 名命名，同名不同内容追加编号，避免覆盖共用资源。保存前检查修订号与主文件外部修改冲突。下载工程副本与导出独立保留。
